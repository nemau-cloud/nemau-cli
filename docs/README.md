# nemau user guide

This guide describes the `nemau` command-line client in more detail than the
[README](../README.md). For the arguments and flags of one command, see the
[command reference](commands/README.md) or run `nemau <command> --help`.

- [Configuration](configuration.md): credentials, API URL, project selection, the local configuration file and shell completion.
- [Output](output.md): tables, JSON, ids only, and what goes to standard error.
- [Asynchronous writes](asynchronous-writes.md): tasks, waiting, timeouts, retries and idempotency keys.
- [Updating resources](updating-resources.md): what changes in place and what is fixed at creation.
- [Exporting data and infrastructure](export.md): object storage downloads, S3 keys and the Terraform export.
- [Scripting](scripting.md): exit status, standard streams, CI jobs and safe re-runs.
- [Examples](examples.md): common tasks from start to finish.
- [Command reference](commands/README.md): every command and flag, generated from the help texts.
